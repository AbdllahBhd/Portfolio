The context

MATMAK was already a production product when I joined. The responsibility is not a greenfield rewrite: it is to extend an existing application while protecting day-to-day stability and continuing to support real business operations.

The platform brings together user access, subscriptions, invoicing, pricing, credits, vehicle-pattern and cutting workflows, customer-facing pages, and administration.

Contribution boundary: this is team product work. I do not present the whole MATMAK platform as an application I independently created.

What I contribute

  • Extend ASP.NET Core APIs, Razor Pages, services, and business workflows.
  • Modernize customer-facing pages and administration interfaces from an older, minimal experience.
  • Work on authentication, subscriptions, invoicing, pricing, credits, and cutting operations.
  • Integrate Stripe for one-time payments, recurring subscriptions, invoicing, and webhook-based status updates.
  • Work directly with management and the team on requirements, releases, and client delivery.

The solution is organized into API, Client, Admin, Models, and Services projects. I describe it as a modular multi-project solution; those project names alone do not prove a microservices architecture.

Data and performance

My work includes EF Core query tuning and database schema redesign. The CV reports an improvement of about 40% in affected read/write operations. The public portfolio keeps that number out of the headline until its workload, baseline, and measurement method can be documented.

Production delivery

The role extends beyond application code. I provision and configure Linux cloud and VPS servers, including SSH access, hardening, firewalls, Nginx, TLS, and application runtimes. I also work with AWS EC2, automated backups, staging environments, and GitHub Actions.

Observability work uses Prometheus, Grafana, Loki, and Promtail for metrics and logs. Internal addresses, customer data, and security configurations are deliberately excluded from this public case study.

What this demonstrates

This work shows how I operate inside an established product: understanding existing constraints, extending business-critical workflows, connecting interface and backend changes, and staying involved through deployment.

The next evidence upgrade is an approved before/after interface view and a measured performance note using synthetic or redacted data.
