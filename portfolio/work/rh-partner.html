The context

RH Partner was already in production. The work was to maintain and extend its backend services, not to rebuild them.

The services

  • Maintained and extended the Spring Boot REST microservices behind the product.
  • Each service runs in its own Docker container, alongside SQL Server in Docker.
  • APIs secured with JWT.

Making queries faster

I designed database schemas and optimised SQL queries, which made the affected queries about 35% faster.

Tests and releases

  • Wrote JUnit unit and integration tests, reaching over 90% coverage in the tested scope.
  • Resolved production defects to keep releases reliable.

What this shows

Backend work on a live product in a second stack: Java and Spring Boot services, containerised, measured on query speed and test coverage.
