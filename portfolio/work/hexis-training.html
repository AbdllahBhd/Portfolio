The product problem

Training operations involve more than a public catalogue. Customers need to discover sessions by topic and location, register, receive transactional communication, and complete assessment steps. Staff need a structured way to maintain planning, locations, certifications, registrations, and results.

The application is multilingual and separates the public React experience from the Laravel application and Filament administration.

For Hex’pert registration, the application emails a quiz link, handles completion and automatic submission, calculates the score, and returns the result. That workflow is a stronger expression of application design than a list of framework names.

My contribution

  • Designed the system and implemented the public and administration experiences.
  • Built planning, location, registration, certification, and transactional-email capabilities.
  • Implemented the assessment sequence, including link delivery, automatic submission, scoring, and results.
  • Used AI-assisted development with Cursor, Codex, custom skills, and MCP while reviewing and validating changes before release.

Technology context: this project demonstrates React experience, but its backend is Laravel—not .NET. The portfolio keeps that distinction explicit.
