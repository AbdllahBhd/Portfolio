The scope

The client needed a store that actually takes money and keeps running, not just a theme install. The work covered both the software and everything needed to put it in production.

Custom application work

I built custom pages and PHP functionality beyond standard WordPress configuration, including custom plugins for import and export, and API integrations that connect the store to the client's wider operations.

Payments

I set up and configured Stripe and Network International for UAE checkout, so customers can pay with the methods they expect locally. Credentials, transaction data and internal settings are kept out of this page.

Infrastructure and launch

  • Provisioned and configured the Linux hosting environment.
  • Connected the domain and DNS, and set up Google Workspace email.
  • Coordinated custom development, payment setup, testing and go-live.
  • Continued support on performance, security and usability after launch.

What this shows

Responsibility beyond isolated features: the store had to be built, integrated, configured and made operational, and it is live today.
