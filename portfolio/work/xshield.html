Custom application work

I built custom pages and PHP functionality beyond standard WordPress configuration, including custom plugins for needs such as import and export. API integrations connected the store to the wider operational context.

The case study describes the specific engineering contribution instead of using “WordPress” as either a shortcut for simple configuration or an inflated claim of a custom platform.

Payment integrations

I created and configured Stripe and Network International integrations for UAE e-commerce checkout. The public case study intentionally excludes credentials, transaction details, internal configuration, and unverified claims about conversion or revenue.

Operational delivery

  • Provisioned and configured the Linux hosting environment.
  • Connected the domain, DNS, and professional email.
  • Coordinated custom development, payment setup, testing, and go-live.
  • Continued support around performance, security, and usability.

This work is useful evidence for full-stack roles because it shows responsibility beyond writing isolated features: the application had to be configured, integrated, and made operational.
